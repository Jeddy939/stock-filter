# Legacy snapshot

`legacy/original/` contains the original app/code files from the repository state before the cache, web UI, scan labelling, and ASX ticker-list updates were added.

This keeps the old desktop/Tkinter-oriented version available in the repository while the root project moves forward with the newer SQLite-backed web workflow.

The bulky historical generated JSON snapshot from the old repo is not duplicated here to avoid bloating this branch; it remains available from the original Git history on `main`.
